3-Step LAN Setup & Play

Host on one laptop, then connect phones and tablets over Wi-Fi.

STEP 1

Start the Host Server

Clone the repository and start the dev server (requires Node.js 20+):

npm install && npm run dev
STEP 2

Connect Local Devices

Vite prints a Network URL (e.g. http://192.168.1.50:5173). Open it on any phone or laptop on the same Wi-Fi.

STEP 3

Join via Room Code

Create a room on the host, share the 4-letter room code, choose a mode, and draw your way to victory!

Controls Reference

Seamless desktop mouse/keyboard and mobile touch controls.

💻 Desktop Controls

  • Move W A S D
  • Look around Mouse Move
  • Fire pencil Left Click
  • Jump / Double Jump Space
  • Draw magic ink Q
  • Erase your drawing Hold G
  • Scoreboard Hold Tab

📱 Mobile Touch Controls

  • Move joystick Left Joystick
  • Look / Aim Right Drag
  • On-screen Fire FIRE Button
  • Draw overlay DRAW Button
  • Cast sketch CAST Button
  • Erase ink ERASE Button
  • Toggle scores Tap Room Code
